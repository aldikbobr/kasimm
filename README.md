# Сайт-портфолио Касыма Амангельдина

Барбер из Петропавловска, чемпион Азии и Европы, основатель Kasym Barbershop.

Это **личный** сайт, не сайт барбершопа. Сайт компании живёт отдельно:
<https://kasim-barbershop.vercel.app>

## Как запустить у себя

Нужен Node 18 или новее.

```bash
npm install
npm run dev
```

Откроется на <http://localhost:5173>.

Остальные команды:

| Команда | Что делает |
|---|---|
| `npm run build` | собирает сайт в папку `dist` |
| `npm run typecheck` | проверяет типы |
| `npm run lint` | проверяет код |

## Как выложить

Репозиторий подключается к Vercel напрямую, настраивать ничего не нужно —
Vite определяется сам. Подробности в разделе «Выкладывание» ниже.

После деплоя **обязательно** проверить адрес сайта: он прописан абсолютным
в шести местах `index.html` (теги `og:`, `twitter:`, `canonical` и два поля
в разметке schema.org). Роботы мессенджеров не выполняют JavaScript, поэтому
подставить адрес скриптом нельзя — только текстом. Если адрес не совпадёт,
превью ссылки в WhatsApp и Telegram придёт без картинки.

## Что где лежит

```
src/
  App.tsx              порядок секций
  data.ts              все тексты, цифры, ссылки, отзывы
  index.css            цвета, шрифты, анимации появления
  components/
    Header.tsx         шапка и мобильное меню
    About.tsx          первый экран — он же герой, несёт <h1>
    Stats.tsx          полоса цифр
    Regalia.tsx        регалии лентой + фото кубков
    Works.tsx          галерея: параллакс на компьютере, сетка на телефоне
    Education.tsx      курс и мастер-классы
    Reviews.tsx        водопад отзывов, колонки едут сами
    Contact.tsx        запись и филиалы
    Footer.tsx         соцсети
public/                фотографии и герб
```

Тексты и цифры правятся в одном месте — `src/data.ts`. Лезть в компоненты
ради смены телефона или отзыва не нужно.

## Две ловушки, на которые уже наступали

**1. Анимация съедает `transform`.** У классов `.rv` и `.rv-kids` в
`index.css` стоит `animation-fill-mode: both`, и последний кадр ставит
`transform: none`. В каскаде анимация сильнее обычного правила, поэтому
любой `scale` или `translateX` на таком элементе стирается. Из-за этого
портрет в герое уезжал от центра, а карточки в галерее не увеличивались.

Лечится так: центровка — через `left: 0; right: 0; margin-inline: auto`
без `transform`, а масштаб вешать на **вложенный** узел, у которого
анимации нет.

**2. Адрес сайта в мета-тегах.** См. раздел «Как выложить».
